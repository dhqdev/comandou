O modelo padrão do Comandou já é no estilo cupom (logo, nome grande, campos em coluna, tabela de
itens, total grande, traços). Para "mais bonito" ou "voltar como era", use `padrao` e diga em uma
frase o que mudou. Pedidos pontuais ("total maior") usam as outras skills.

```json
{"tipo": "padrao"}
```
